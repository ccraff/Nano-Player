# Nano (PWA) – iPod nano + Spotify
1. Sube estos 5 archivos a un repositorio de GitHub (raíz) → Settings → Pages → Deploy from branch (main / root).
2. Tu URL será https://USUARIO.github.io/REPO/ (con la barra final).
3. En developer.spotify.com/dashboard → tu app → Settings → Redirect URIs: añade EXACTAMENTE esa URL y guarda.
4. En Chrome del F22 abre la URL → menú ⋮ → "Instalar app" / "Añadir a la pantalla principal".
